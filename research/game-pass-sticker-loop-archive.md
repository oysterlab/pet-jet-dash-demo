# Game Pass and Sticker Collection Loop Archive

Date: 2026-05-03

## Product Loop

The product should be sold as a 7-day personalized pet game pass, not as a raw AI asset purchase.

## Core Offer

7-Day Pet Game Pass:

- User uploads one pet photo.
- The service generates a playable pet character.
- The user can play the personalized game for 7 days.
- The game can be played via web and should eventually support download/offline play through PWA or a lightweight downloadable build.
- During the 7-day period, the user collects personalized PNG stickers through gameplay.
- Already collected stickers remain downloadable after the pass expires.

## Reward Structure

Sticker rewards should be collected in-game as item drops rather than given all at once.

Recommended item loop:

- Snacks: score and combo.
- Boost Battery: boost meter.
- Sticker Capsule: sticker or sticker fragment.
- Golden Capsule: guaranteed new sticker.
- Lucky item: improves chance of a useful capsule.

## Sticker Book

The main collection target is a 6-sticker set for the user's pet.

Candidate stickers:

- Happy Pet
- Snack Master
- Tiny Pilot
- Brave Baby
- Dramatic Oops
- Golden Pet

## Anti-Frustration Rules

Avoid pure random loot-box dynamics.

Rules:

- No duplicates until the first sticker set is complete.
- Every run should make visible progress.
- First sticker should be obtainable within the first 1-3 runs.
- Daily first play should guarantee progress.
- Failing a run should still grant fragments or progress.
- Users should normally be able to complete the 6-sticker set within 7 days without grinding heavily.

## Positioning

Good copy:

- "Play to collect all 6 stickers."
- "Every run makes progress."
- "Complete your pet's sticker book."
- "No duplicates until your set is complete."

Avoid:

- "Random sticker gacha."
- "Rare drop rate."
- "Buy capsules."
- "Loot box."

## Monetization

The initial paid product should be the 7-day game pass.

Suggested test prices:

- Launch test: $1.99.
- Stronger baseline: $2.99.
- Premium pack later: $4.99-$7.99 for more styles, more stickers, GIF/video exports, or creator tools.

Payment framing:

- User is buying a limited-time personalized game experience and sticker collection quest.
- Stickers are earned through play, which makes the final output feel more valuable than a one-click image generation.

## Strategic Rationale

This structure connects the AI image generation and the game mechanics:

- AI creates personal attachment.
- The game creates effort and memory.
- Sticker drops create reward anticipation.
- The sticker book creates completion motivation.
- PNG stickers create reusable social value in messengers and SNS.

The main risk is frustration if rewards feel withheld after payment. The solution is guaranteed progress and no duplicate friction during the first set.
